# Форк LearnHarness

Этот репозиторий содержит доработанную версию [LearnHarness](https://github.com/amosblomqvist/learnharness) под лицензией AGPL-3.0. Основа — **v0.4.1**, коммит `e69e85269c064c6c9c49a8b06ae78c06e79c4a63`. Автор исходного приложения — Amos Blomqvist; доработки поддерживаются в [matveyvarfolomeeev/learnharness](https://github.com/matveyvarfolomeeev/learnharness).

## Отличия от автора

| Возможность | Что изменено |
|---|---|
| Проекты знаний | Иерархия проектов и подпроектов, ручной выбор темы и переключатель автоматического определения. Удаление проекта переносит знания и занятия в выбранный проект или «Без проекта»; узлы, связи и статусы сохраняются. Подпроекты переходят под выбранный проект, а при выборе «Без проекта» становятся самостоятельными. |
| Освоение и Practice | Статусы «Не проверял», «Изучаю», «Знаю», «Нужно повторить», фильтр графа, история связанных проверок и адаптация практики к доступным данным. Импорт или чтение сами по себе не доказывают освоение. |
| Импорт | Обобщённые понятия, теоремы и методы с русскими названиями вместо отдельных упражнений. Импорт папок и PDF из v0.4.1 сохраняет выбранный проект каждого набора файлов. |
| Список знаний | По умолчанию открывается дерево «По проектам», объединяющее знания из разных занятий и импортов. Галочки проектов дают действия «Практиковаться» по их знаниям и «Удалить с переносом» для нескольких проектов сразу. Удаляются только явно выбранные проекты; неподтверждённых изменений нет. «По источникам» показывает исходные файлы и диалоги; источники без узлов скрыты до включения «Показать пустые». Выбор знаний для Practice сохраняется при переключении. |
| Диктовка | Deepgram, Whisper large-v3 и Whisper Turbo через Groq; выбор модели и ключ в Settings → Providers → Dictation, автоматическая пунктуация, словарь терминов и необязательная очистка текста. |
| Быстрые ответы | Настройка Fast для поддерживаемых разговорных запросов через подключение ChatGPT; не заменяет выбранный уровень рассуждений. Доступность и лимиты зависят от провайдера. |
| Уведомления | Desktop-уведомление, когда преподаватель ждёт ответа и окно приложения не в фокусе. Включается в Settings → General. |
| Уточнения | Вопрос по выделенному фрагменту и отдельный ответ во всплывающем диалоге, без добавления этой переписки в основное занятие. |
| Демонстрации | Компактная карточка, открытие справа или на всю область занятия, независимое включение шагов. Ползунки и состояние iframe сохраняются при переключениях и закрытии; старые HTML-демки совместимы. Настройки: Appearance → Демонстрации. |
| Отзывчивость | Локальные изменения рендера чата, работы диктовки, контроля длительных ответов и порога сжатия контекста. |

Папки в Chains организуют **источники**, а проекты задают **учебные темы**. Эти структуры работают одновременно. Новая модель и ключи не выбираются автоматически за пользователя.

## Запуск нашей версии

Нужны Git, Node.js 26 и npm. Зависимости устанавливаются по lockfile. Готового установщика форка пока нет; загрузки автора не содержат эти изменения.

```sh
git clone https://github.com/matveyvarfolomeeev/learnharness.git
cd learnharness
npm ci
npm run desktop:dev
```

`desktop:dev` запускает локальный сервер и Electron. Он позволяет использовать desktop-уведомления. Для работы только в браузере:

```sh
npm run dev -- --hostname 127.0.0.1
```

Открой `http://localhost:3000` и настрой свои модели в Settings → Providers / Agent. Groq, Deepgram и поиск подключаются отдельно при необходимости. У каждого пользователя собственные ключи, диалоги и граф; личная база владельца форка не распространяется.

Для production-сборки веб-приложения: `npm run build`, затем `npm start -- --hostname 127.0.0.1`. Правила упаковки Electron описаны в [desktop-release.md](desktop-release.md). Скрипт `desktop:dist` автора требует настроенной macOS-подписи, поэтому это не универсальная команда сборки Windows-установщика. Источник обновлений будущих desktop-сборок форка указывает на этот репозиторий.

Приложение рассчитано на доверенное локальное использование. Не публикуй свой dev-сервер в интернете: он не является сервисом с отдельными аккаунтами пользователей. Подробности хранения и подключений — в [development.md](development.md).

## Как получать обновления автора

`origin` — твой форк, `upstream` — исходный репозиторий. Основная ветка `main` содержит доработки; историю автора сохраняем, чтобы обновления объединялись обычным Git merge.

Один раз после клонирования:

```sh
git remote add upstream https://github.com/amosblomqvist/learnharness.git
```

Перед обновлением сохрани текущие изменения коммитом и сделай резервную копию своих учебных данных. Затем:

```sh
git switch main
git fetch upstream --tags
git log --oneline main..upstream/main
git merge --no-edit upstream/main
```

Если появились конфликты, совмести изменения, затем выполни проверки и зафиксируй результат. При изменении зависимостей снова запусти `npm ci`.

```sh
npm run typecheck
npm run lint
npm run build
```

Тесты в Linux/macOS: `npm test`. В PowerShell, где Unix-запись `NODE_ENV=test` в npm-скрипте не работает:

```powershell
$env:NODE_ENV = "test"
$testFiles = (Get-ChildItem tests -File | Where-Object Name -Match '\.test\.(ts|tsx)$').FullName
node --import tsx --test --test-concurrency=4 $testFiles
Remove-Item Env:NODE_ENV
```

После проверки: `git push origin main`. Не заменяй свою ветку принудительным сбросом на ветку автора: это исключит доработки из её истории. Команда GitHub «Sync fork» не заменяет проверку совместимости.

Полный патч относительно исходной базы можно получить командой `git diff --binary v0.4.1 main`. Для предложения отдельной функции автору удобно создать ветку от `upstream/main` и перенести в неё только нужные изменения.

## Что проверено

Версия с доработками проверена на Windows: TypeScript, ESLint, production-сборка, 235 профильных тестов и 8 проверок перезапуска. В браузере проверены проекты вместе с папками источников, сохранение статуса знания, настройки диктовки, новые и старые демки, четыре сочетания настроек просмотра, сохранение состояния и Escape. Это проверка локальной версии; она не заменяет результат GitHub Actions на конкретном коммите.

Полный локальный набор не полностью зелёный: 26 ошибок воспроизводились и на чистой v0.4.1 в той же среде. Они затрагивают POSIX-права/пути, macOS-инструменты и отсутствующие средства упаковки, проверки KaTeX, обнаружение Claude Code и скрипты релиза. Эти ограничения не объявляются исправленными данным форком.

## Данные и лицензия

В Git входят исходники и синтетические тесты. `data/`, ключи, OAuth-файлы, `.env*`, сборки и личные материалы исключены. Не добавляй их принудительно через `git add -f`.

Лицензия и сведения об исходном авторе сохранены: [AGPL-3.0](../LICENSE). Изменения форка распространяются под той же лицензией. Их можно использовать и предлагать обратно автору с соблюдением её условий.
